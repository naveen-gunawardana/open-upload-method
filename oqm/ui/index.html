    Measure what TikTok served

    Download your posted video from another account or device (or screen-record it at full resolution), drop it in, and compare it against the original.

    Build an A/B upload kit

    Four versions of the same video, each verified, plus a RESULTS.csv to fill in. Upload them to a test account the same way, about an hour apart, in shuffled order. Also log loops_normally and any guideline_flag per arm - that's the only reliable way to find out which patch (if any) is causing either.

    Generate a test card

    A 1080×1920 clip with sharp edges, fine moving detail and smooth gradients, which makes compression easy to see. Every frame is unique, so you can tell real 60 fps from fake.
