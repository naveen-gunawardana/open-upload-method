OQM
Open Quality Method

Workspace

    Export a clean master

    The only step that re-encodes. Feed it your best export (ProRes, DNxHR or a high-bitrate file), not something already compressed.

    Lower = better + bigger. 16–18 is visually transparent.
    Constant rate. Never interpolates.

    Patch the container

    Changes only the MP4's structure, never the picture. Every output is verified against the source before you upload it.

    Advanced

    Measure what TikTok served

    Download your posted video from another account or device (or screen-record it at full resolution), drop it in, and compare it against your master.

    Build an A/B upload kit

    Four versions of the same master, each verified, plus a RESULTS.csv to fill in. Upload them to a test account the same way, about an hour apart, in shuffled order.

    ArmWhat it tests
    A_controlWhat TikTok does to a good file anyway
    B_referenceThe full method
    C_decoy_onlyIs the decoy audio track the part that matters?
    D_structure_only…or is it everything else?

    Inspect a file

    See the MP4 box tree and compare declared vs. actually decoded frame counts. Useful for checking what a paid tool did to your file.

    Generate a test card

    A 1080×1920 clip with sharp edges, fine moving detail and smooth gradients, which makes compression easy to see. Every frame is unique, so you can tell real 60 fps from fake.
